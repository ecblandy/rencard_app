Ainda não sabe onde encontrar?

Escolha o caminho que corresponde à sua situação.

1
Já tenho um fluxo de dados

No Google Analytics, acesse:

Administrador → Fluxos de dados → selecione seu site → copie o ID de medição

O ID será parecido com: G-QYWB792MLT

2
Ainda não tenho um fluxo de dados

Se o Google Analytics mostrar "Escolha uma plataforma" ou você ainda não configurou seu site, faça o seguinte:

  1. 1. Acesse o Google Analytics.
  2. 2. Abra Administrador .
  3. 3. Vá em Fluxos de dados .
  4. 4. Clique em Adicionar fluxo e escolha Web .
  5. 5. Informe a URL do seu site.
  6. 6. Informe um nome para o fluxo.
  7. 7. Crie o fluxo e copie o ID de medição .
